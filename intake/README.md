# Intake

New work enters the system here. Paste the raw input into the relevant template, then feed it to the Orchestrator.

| Template | Use when |
|----------|---------|
| `from-email.md` | Client sent a brief or request by email |
| `from-form.md` | Client completed an intake form / questionnaire |
| `from-call.md` | Work came in via a discovery or scoping call |

## Workflow

1. Open the relevant template
2. Fill in the fields — paste raw content into "Raw input"
3. Copy the completed template and paste it as your first message to the Orchestrator in Claude.ai
4. Save the chain output to `clients/[client-name]/`

## For retainer clients

Retainer requests don't always need a full intake process. If the scope is clear, paste the request directly to the relevant specialist agent (BRD Builder or Proposal Agent), not the full Orchestrator chain. Note the shortcut in the client folder.
