This file tracks all demo briefs used in the course. Each brief is designed to demonstrate a different scenario and surface different behaviours in the agent chain.

## How to Add a New Brief

1. Create the file: `brief-0N.md` (increment the number)
2. Follow the brief format in the existing files
3. Add a row to this index table
4. Commit: `test: add brief-0N.md — [one-line description]`

## Brief Design Principles

Good demo briefs are:
- **Realistic but generic** — drawn from recognisable business situations, but with no real client information
- **Imperfect** — the best briefs have something missing or ambiguous so participants can see how the agents handle incomplete information
- **Varied in complexity** — the three briefs should cover different industries and scope sizes
- **Conversation-starting** — briefs that produce interesting or surprising outputs teach more than briefs that produce perfect outputs
