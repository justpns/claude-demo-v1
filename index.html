FAQ

Common questions

Everything you need to know before you sign up.

Do I need any coding or technical experience?
None at all. This workshop is built specifically for people who have never written code and have no intention of starting. If you can use a browser and write an email, you have everything you need. The whole point is to show you how to get results that used to require a developer — without becoming one.
What tools or software do I need to install?
Nothing to install. The entire workshop runs through Claude Code Web, which is browser-based. You'll need a Claude account (free tier works) and a laptop with a modern browser. That's it. Setup instructions will be sent to registered attendees before the session.
How is this different from learning ChatGPT or Copilot?
Prompt engineering teaches you to ask better questions. This workshop teaches you to build better systems. You'll learn how to design full workflows, chain tasks together using AI orchestration, create reusable routines, and automate multi-step processes — not just get a smarter answer to a one-off question. Claude Code is purpose-built for this kind of structured, agentic work.
Is the workshop really free? What's the catch?
Yes, completely free. No upsell mid-session, no surprise payment wall. The cohort will be kept deliberately small to maintain quality and make sure everyone gets value from it. A waitlist exists because spaces are limited — not to create artificial scarcity. Future advanced workshops may be paid, but this one is not.
Will there be a recording if I can't attend live?
The live experience is intentionally interactive — you'll be building and experimenting in real time, which is hard to replicate in a recording. That said, we plan to record sessions and share them with registered attendees who couldn't make it. Join the waitlist and you'll be the first to know when dates and replays are confirmed.
